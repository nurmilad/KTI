💡 Kemungkinan penyebab login gagal:
  • Firestore Rules memblokir baca → paling umum. Harus ada rule match /password/{doc} { allow read: if true; } dan sudah di-Publish.
  • Nama dokumen salah → harus password (collection) → pwd (document). Huruf kecil semua.
  • Field salah → nama field harus password (lowercase).
  • Ada spasi tersembunyi di value password di Firebase, atau di input Anda.
  • Beda huruf besar/kecil → adminkti ≠ AdminKTI (case-sensitive).
